# Agnes AI 视觉自动化

simpleRPA 的 AI 视觉层用于减少固定坐标和截图模板维护。第一版支持：

- **AI视觉点击**：用自然语言描述按钮，例如“右上角关闭公告的 X”。
- **AI视觉判断**：判断“是否有可领取按钮”，结果写入变量，可继续用于条件流程。
- **AI视觉导航**：自动关闭普通公告/提示，并按目标返回上一层或首页。
- **AI视觉任务**：直接描述一个小任务，由视觉模型连续截图、点击并判断完成状态。

底层仍复用 simpleRPA 已有的窗口绑定、后台截图和后台点击，因此旧的 `.rpa.json` 脚本不需要迁移。

## 配置 Agnes

PowerShell：

```powershell
$env:AGNES_API_KEY="你的Key"
$env:AGNES_API_BASE="https://apihub.agnes-ai.com/v1"
$env:AGNES_MODEL="agnes-3.0-flash"
python main.py
```

也兼容 `AGNESAI_API_KEY`。如果使用 Agnes 国内站或自建兼容代理，只需修改 `AGNES_API_BASE`。

不要把 API Key 保存到 `.rpa.json`、仓库或截图中。

## 推荐使用

### 自动关闭公告并返回首页

添加“AI视觉导航”，填写：

```text
关闭当前公告、活动说明和普通提示；如果不在主界面，逐级返回首页
```

### 直接执行自然语言任务

添加“AI视觉任务”，填写：

```text
如果有公告先关闭，然后返回首页，进入签到页面，把免费的可领取奖励领取完，完成后返回首页
```

视觉任务会在每次点击后重新截图并继续判断，直到模型返回完成或达到最大步骤数。

### 条件判断

添加“AI视觉判断”：

```text
当前页面是否存在“免费领取”按钮
```

结果变量设置成 `free_reward`，后续条件可填写 `$free_reward`。

## 安全边界

视觉 Agent 的系统提示禁止自动执行购买、支付、充值、消耗货币、删除数据、账号安全设置和敏感授权。视觉导航主要负责关闭公告、普通提示、返回和回首页。

建议先在测试账号或低风险任务上验证 UI 识别效果。

## 当前限制

- 第一版只执行视觉点击和等待，不处理拖拽、复杂滚动或文本输入。
- Agnes API 的实际视觉请求需要有效 API Key；仓库单元测试使用 Fake Provider，不消耗 API。
- 对话式多轮“改脚本”界面尚未接入；当前“AI视觉任务”已经可以用一句自然语言替代一组坐标/模板动作。
